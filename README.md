A single funny line of text for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on make.fun. The program writes one line (at most 200 characters) to `/output/entry.txt`, where an AI judge compares entries two at a time and picks the funnier one.

## The line

> My screen time report just filed a restraining order against me.

## How it runs

```sh
node main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default). No network, no dependencies, no build step.
